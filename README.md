# Library Feed

**[最新版をDL](https://github.com/Hiroyamahiro/libraryfeed/releases/download/v0.5.0/LibraryFeed-0.5.0.zip)**

漫画やサイトの更新をまとめて確認する、Windows用ブラウザ拡張機能です。
Chrome、Edge、Vivaldiに対応しています。

## 導入手順

1. ZIPを解凍する。解凍後のフォルダーは任意の場所に置く。
2. ブラウザのアドレスバーに貼り付け： `chrome://extensions`
3. **デベロッパーモード**をON → **パッケージ化されていない拡張機能を読み込む** → 展開した中の **LibraryFeed** を選択。Edgeは「開発者モード」→「展開して読み込み」。
4. ブラウザ右上の拡張機能メニューから開く。

**※読み込み後はフォルダーを移動・削除しないでください。**

## Edge・Vivaldiで同期を使う場合

解凍したフォルダー内の **LibraryFeedSetup.exe** を実行します。
ファイルを直接、一回だけ実行してください。
その後、LibraryFeedで同期を実行します。

同期なしでも使えます。
