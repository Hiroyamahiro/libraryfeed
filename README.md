# Library Feed

**[最新版をDL](https://github.com/Hiroyamahiro/libraryfeed/releases/download/v0.5.0/LibraryFeed-0.5.0.zip)**

漫画やサイトの更新をまとめて確認する、Windows用の拡張機能です。

1. ZIPを右クリック → **すべて展開**。
2. ブラウザのアドレスバーに貼り付け：Chromeは `chrome://extensions`、Edgeは `edge://extensions`、Vivaldiは `vivaldi://extensions`。
3. **デベロッパーモード**をON → **パッケージ化されていない拡張機能を読み込む** → 展開した中の **LibraryFeed** を選択。Edgeは「開発者モード」→「展開して読み込み」。

ブラウザ右上の拡張機能メニューから開けます。読み込み後はフォルダーを移動・削除しないでください。

Edge・VivaldiでGoogle同期を使う場合だけ、同梱の **LibraryFeedSetup.exe** を実行します。同期なしでも使えます。
